# Weather Tracking & Analysis Dashboard

Web application that ingests weather data from external providers, stores and analyses
time-series history, and presents current conditions, trends and alerts through an
interactive dashboard.

Built incrementally from `Weather_Dashboard_WBS.xlsx`. The **project foundation &
scaffolding** (backend, frontend and CI) lands in the first pull request; each
subsequent pull request implements a single WBS task.

See the open pull requests for work in progress.
